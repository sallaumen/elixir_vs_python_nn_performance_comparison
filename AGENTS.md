# Contributor and AI agent guidance

This repository is the overview for two separate implementation repositories. Read `README.md` and `docs/methodology.md` before editing claims about performance or status.

- Keep this repository focused on context, links, and methodology. Put executable Python and Elixir changes in their respective repositories.
- Check implementation source before changing a status or architecture claim here. Cite the relevant repository and distinguish historical figures from fresh measurements.
- Do not report a language speed winner from the current code: model structure, optimizers, batch size, and backend settings differ.
- Write documentation and contribution guidance in clear English. Keep commands copyable and links relative for local files.
- For any future benchmark, record exact commits, environment, timing boundary, raw runs, and held-out metrics as described in `docs/methodology.md`.
